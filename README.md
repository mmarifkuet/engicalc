# ⚙️ EngiCalc - Engineering Calculation Toolkit

EngiCalc is a Streamlit-based web application designed for mechanical engineering calculations and analysis.

## 🚀 Features

- **Mechanics**: Calculate Force, Torque, and Power.
- **Modular Structure**: Clean separation of calculation logic and user interface.
- **Interactive UI**: Built using Streamlit for fast and intuitive input/output.
